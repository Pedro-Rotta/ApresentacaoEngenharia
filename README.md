# Calculadora (Apresentação de Engenharia)

Calculadora web em **HTML, CSS e JavaScript**, desenvolvida para uma apresentação acadêmica no curso de Sistemas de Informação da Unoeste.

## Funcionalidades
- Soma, subtração, multiplicação, divisão e porcentagem
- Apagar o último dígito (⌫) e limpar tudo (C)
- Visor com a operação anterior e o valor atual

## Organização do código
```
index.html          tela da calculadora
css/style.css       estilos
js/main.js          eventos dos botões e controle do visor
js/operations/      uma função por operação (somar, subtrair, multiplicar, dividir, porcentagem)
js/utils/           apagar e limpar
```

As pastas `adicionarSoma/` e `AdicionarCores/` guardam as etapas usadas durante a apresentação.

## Como rodar
Abra o arquivo `index.html` no navegador. Não precisa instalar nada.
